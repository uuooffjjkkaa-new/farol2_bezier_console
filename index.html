Quick guide

Interaction
  • First make sure the planner node has been launched ("Planning Node Active" will be green)
  • Add a vehicle and control its initial state with the left button of the mouse (you can adjust its initial angle and velocity dragging the handle).
  • While a vehicle is selected it is possible to add a goal to it by click and dragging with the right button of the mouse.
  • Add obstacles and alter their shape by clicking and dragging with the right mouse button.
  • Zoom in on the map by holding the "alt" key while spinning the mouse wheel.
Typical workflow
  1. Mission Setup: add vehicles and obstacles, and place a goal for each vehicle.
  2. Tick the vehicles to use in Active Vehicles.
  3. Optimization → Run. Use Trajectories → Display to show the result on the map.
  4. Execution: On the "Execution" tab start PF or CPF for the active vehicles, then Mission → Deploy. Cancel stops the mission.
Notes
  • Use State from ROS (Execution tab): vehicles are taken from the running simulation instead of being added by hand, initial states come directly from the simulation.
  • Planner Definition: bounds, cost gains and Bézier parameters. Load From Solver reads the current values, Apply Changes sends yours.
